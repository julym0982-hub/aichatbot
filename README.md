# AI Userbot (Groq) — Render + MongoDB

1. `.env.example` ကို Render Environment Variables အဖြစ်ထည့် (BOT_TOKEN, API_ID, API_HASH, ADMIN_ID, MONGO_URI, RENDER_EXTERNAL_URL)
2. Start command: `npm start` (Node 18+)
3. Account session string ထုတ်ဖို့ ကိုယ့်စက်မှာ `npm i && node get-session.js`
4. Bot ကို /start → ➕ Account ထည့် → 🔑 Groq Keys → ➕ GP ထည့် → 🤝 Join → ▶️ Start
